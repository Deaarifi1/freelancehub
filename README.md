# FreelanceHub

Modern web platform that connects freelancers with clients and agencies in a unified ecosystem.

## Technologies

| Layer | Technology |
|---------|-------------|
| Backend | Python + FastAPI |
| Database | PostgreSQL |
| ORM | SQLAlchemy + Alembic |
| Authentication | JWT (python-jose) |
| Cache | Redis |
| Background Jobs | Celery |
| AI Module | OpenAI GPT-4o |
| Frontend | React |
| Testing | Pytest |
| CI/CD | GitHub Actions |
